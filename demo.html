A WORKING EXAMPLE OF THE METHOD

One booking slot.
Two different timestamps.

Here is the fault, the change and the check. This example was built for demonstration. It is not customer work or a live booking service.

THE FAULT /

The app stores reservations as timestamp strings. 2026-09-25T14:00:00Z and 2026-09-25T15:00:00+01:00 are the same instant, but their text differs. A raw text comparison accepts both bookings.

BEFORE✕ duplicate accepted
def book(existing_slots, requested_slot):
    if requested_slot in existing_slots:
        return False
    existing_slots.add(requested_slot)
    return True
AFTER✓ duplicate rejected
requested = normalize_slot(requested_slot)
if any(normalize_slot(slot) == requested
       for slot in existing_slots):
    return False
existing_slots.add(requested_slot)
return True
THE CHECK /

The test starts with a 14:00 UTC booking, then attempts 15:00 UTC+1. The original version accepts a second booking; the repaired version rejects it. The suite also checks a distinct time and invalid or missing timezones.
