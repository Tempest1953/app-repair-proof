# App Repair Proof

Static GitHub Pages site for App Repair Proof, led by Gareth Price in the UK. Presents a scoped $500 one-fault repair, a synthetic before-and-after example, and an email contact route. No payment collection, analytics, or server.

## Publishing

GitHub Pages source: main branch, repository root. Public URL: https://gareth1953.github.io/app-repair-proof/ after Pages is enabled and built.

## Local check

Run python3 -m unittest -v test_booking.py from the demo directory. Serve locally with python3 -m http.server 8000 and inspect the home and demo pages at desktop and phone widths.

## Truth boundary

The demo is synthetic and in-memory. Customer results, automated repair capabilities, and production readiness are not claimed. PayPal invoicing follows an agreed scope for direct customers. Do not publish personal or client credentials in this repository.
